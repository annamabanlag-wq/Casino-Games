# PeryaPH — JILI Game Content Partnership Inquiry

**Purpose:** Request evaluation and onboarding guidance for an independent game portfolio  
**Project:** PeryaPH  
**Developer portfolio repository:** https://github.com/annamabanlag-wq/Casino-Games  
**Demo URL:** https://annamabanlag-wq.github.io/Casino-Games/

## Partnership request

PeryaPH is an independent Filipino perya-inspired arcade game project. We would like to ask JILI Games whether it accepts submissions from independent game developers or can direct us to an authorized game-distribution/aggregation partner for technical evaluation.

We are seeking a preliminary review and onboarding guidance, not claiming acceptance, certification, or a current commercial partnership.

## Original game concepts in the portfolio

- Triple Spin — reel-matching arcade demo
- Color Wheel — color-wheel selection demo
- High Card — card comparison demo
- Dice Duel — dice comparison demo
- Gem Hunt — pick-a-gem demo
- Lucky Number — number-guessing demo
- Video Karera — numbered-horse racing demo inspired by Filipino perya arcades
- Color Game — color draw demo inspired by Filipino perya arcades
- Beto-Beto Dice — three-dice guessing demo inspired by Filipino perya arcades
- Number Ball — numbered-ball draw demo inspired by Filipino perya arcades

The current public build is a browser-based virtual-credit prototype. Game availability and behavior should be evaluated directly from the demo; the project is not represented as certified or ready for real-money deployment.

## Questions for JILI

1. Does JILI accept original game submissions from independent developers, or does it work only with contracted studios, licensed operators, or approved aggregators?
2. What are the current technical specifications for game submission (HTML5/WebGL requirements, APIs, game-session integration, reporting, security, and supported devices)?
3. What game math, RNG testing, independent laboratory certification, security review, and regulatory approvals are required?
4. What company, ownership, IP, and compliance documentation must a developer provide?
5. What commercial models may be considered (licensing, revenue share, or another distribution agreement), and what are the applicable minimum requirements?
6. For the Philippines, what licensed operator and PAGCOR approval/accreditation path must be in place before any real-money use?
7. Is there a secure process for sharing source code or a technical build for evaluation?

## Proposed next step

If JILI is open to this type of submission, please provide the official game-provider onboarding process and the required technical/commercial checklist. We can then prepare a formal submission package for the selected games.

## Compliance and IP notes

- The current app uses virtual credits only; no deposits, cash wagers, or withdrawals are enabled.
- No claim is made that PeryaPH or its games are licensed, certified, or approved by JILI or PAGCOR.
- Any real-money launch would be subject to the applicable written approvals, testing, contracts, and licensed-operator/provider arrangements.
- Source code and original assets will be shared for evaluation only through an agreed secure process and under appropriate confidentiality/IP terms.
